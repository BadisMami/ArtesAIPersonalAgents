# Example Input: Scientific Figure Recreator

### 1. Upload the Sample Figure Image
Click **`+` → `Add Files & Images`** in the ArtesAI chat bar and upload [`sample-paper-figure.png`](./sample-paper-figure.png):

![Sample Two-Panel Scientific Figure](./sample-paper-figure.png)

### 2. Attach Your Preferred Language Skill
Click **`+` → `Skills >`** and select the language skill you want to use:
- `figure-recreator-python` (`/python`)
- `figure-recreator-r` (`/r`)
- `figure-recreator-stata` (`/stata`)
- `figure-recreator-matlab` (`/matlab`)

### 3. Paste This Prompt into the Chat

```text
Please deconstruct this 2-panel figure from a paper and write a complete, self-contained script with realistic synthetic data so I can reproduce this exact figure style on my local computer and swap in my own CSV later.
```
